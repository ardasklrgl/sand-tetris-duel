# README media

Add the website demo videos, GIFs and screenshots here. No media has been added yet.

Suggested filenames:

- `demo.gif` — the main demo below the README headline.
- `duel.gif` — a short human vs AI match.
- `practice.gif` — switching modes and inspecting AI hints.

The root README has commented slots for these clips. For a GIF, replace its comment with an embed such as:

```md
![Practice mode and AI hints](assets/readme/practice.gif)
```

For an inline video, upload it through GitHub's README editor and paste the generated attachment URL into the main demo slot. A relative link to an MP4 file is a download/link, rather than the inline video player.
